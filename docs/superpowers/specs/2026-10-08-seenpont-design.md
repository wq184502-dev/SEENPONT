# SEENPONT 설계 문서

작성일: 2026-10-08 · 상태: 사용자 검토 대기

## 1. 목적

웹이나 이미지에서 마음에 드는 폰트를 만났을 때, SEENPONT로 폰트를 식별하고 합법적으로 사용할 수 있는 가장 빠른 경로(다운로드 또는 구매)까지 연결하는 데스크톱 앱.

### 성공 기준
- 이미지 속 글자 또는 복사한 웹 텍스트에서 폰트 후보를 보여 준다.
- 라이선스가 확인된 무료 폰트는 앱에서 바로 다운로드하고 설치한다.
- 유료 폰트는 구매 페이지로 연결하고, 비슷한 무료 대체 폰트를 제안한다.

### 비목표 (하지 않는 것)
- 라이선스 없이 유료 폰트를 구해 주는 기능. 크랙·토렌트·웹사이트의 폰트 파일 추출은 만들지 않는다.
- 브라우저 확장 프로그램 (스토어 삭제 위험. 필요하면 나중에 보조 입구로 추가).
- 자체 학습 모델 (3단계 이후).

## 2. 확정된 결정

| 항목 | 결정 |
|---|---|
| 형태 | 데스크톱 앱 |
| 지원 OS | Windows + macOS |
| 프레임워크 | Electron |
| 입력 방식 | 클립보드 (이미지 또는 HTML 서식) |
| 식별 엔진 | 로컬 매칭 (외부 서비스는 나중에 선택적으로 추가) |
| 저작권 정책 | 라이선스가 확인된 폰트만 자동 다운로드, 유료는 구매 연결 |

## 3. 구조와 흐름

```
Win+Shift+S → 클립보드 이미지 ──┐
                                 ├→ SEENPONT 단축키 → 식별 → 결과 화면
드래그 → Ctrl+C → 클립보드 HTML ─┘                      ├ 무료/재배포 허용 → [다운로드 + 설치]
                                                       └ 유료 → [구매 페이지] + [무료 대체 폰트]
```

Mac은 Cmd+Ctrl+Shift+4로 영역을 클립보드에 캡처한다. 클립보드 이미지의 자동 감지는 선택 옵션이고, 기본은 단축키 또는 앱 창에 붙여넣기다.

### 구성 요소 (각각 독립적으로 구현·테스트)
- **클립보드 입력:** 클립보드에서 이미지 또는 HTML을 읽어 내부 입력 형식으로 변환한다.
- **HTML 파서:** 복사된 HTML의 `font-family` 등 스타일을 읽어 폰트 이름 후보를 추출한다. 결과는 "추정"으로 표시한다. CSS 우선순위 목록이라 실제 렌더링 폰트를 확정하지 못하기 때문이다.
- **식별 엔진:** 이미지를 받아 글자를 인식하고 카탈로그의 폰트와 비교해 후보 3~5개를 확률과 함께 돌려준다. 내부 구현을 바꿔도 다른 모듈에 영향이 없는 하나의 인터페이스로 둔다.
- **폰트 카탈로그:** 폰트별 이름, 라이선스, 다운로드 URL, 구매 URL, 대체 후보, 식별용 특징 벡터.
- **라이선스 판별:** 카탈로그에 기록된 라이선스(OFL, Apache 등)만 자동 다운로드로 분류한다. 모호하면 공식 페이지 연결만 한다.
- **설치 모듈:** 받은 폰트를 사용자 폰트 폴더에 저장하고 OS에 등록한다.
- **결과 화면:** 후보별로 다운로드/구매/대체 폰트 행동을 보여 준다.

## 4. 폰트 카탈로그

- 1단계는 Google Fonts 등 재배포가 허용된 출처에서 시작한다.
- 식별용 특징 벡터는 사전에 계산해 앱에 포함한다. 실행 시 계산하지 않는다.
- 카탈로그는 앱 배포와 별도 파일로 두어 갱신할 수 있게 한다.
- 한국 폰트는 라이선스가 제각각이라 1단계에서 제외하고, 2단계에서 항목별 확인 후 추가한다.

## 5. 오류 처리

- 클립보드가 비었거나 이미지·서식이 아니면 안내 메시지를 보여 준다.
- 식별 확률이 낮으면 단정하지 않고 "비슷한 후보"로 표시한다.
- 다운로드나 설치에 실패하면 원인과 수동 다운로드 링크를 보여 준다.
- 라이선스가 불명확한 폰트는 자동 다운로드하지 않고 공식 페이지로만 연결한다.

## 6. 테스트

- **식별 정확도:** 알려진 폰트로 만든 샘플 이미지 세트에서 상위 5개 후보에 정답이 들어오는 비율을 측정한다.
- **HTML 파싱:** 실제 브라우저에서 복사한 샘플로 단위 테스트한다. 구현 초기에 브라우저별 클립보드 내용을 실제로 확인한다.
- **라이선스 분류:** 허용·불허 케이스를 전부 테스트하고, 모호한 경우가 자동 다운로드로 빠지지 않는지 검증한다.

## 7. 단계

1. **1단계:** 클립보드 이미지·HTML 입력, 로컬 매칭 식별, 무료 폰트 다운로드·설치, 유료 폰트 구매 연결과 대체 폰트 제안.
2. **2단계:** 한국 폰트 등 카탈로그 확장, 외부 식별 서비스 연동(선택).
3. **3단계:** 자체 인식 모델, 우클릭 입구가 필요하면 확장 프로그램 보조 추가.

## 8. 알려진 한계

- 카탈로그에 없는 유료 폰트는 정확히 식별되지 않고 가장 비슷한 무료 폰트로 보인다.
- 손글씨, 심하게 변형된 글자, 로고, 저해상도 이미지는 정확도가 떨어진다.
- HTML 경로는 실제 렌더링 폰트를 확정하지 못하는 추정이다.
- 본 문서는 법률 자문이 아니다. 배포 전 라이선스 정책과 약관은 전문가 검토를 받는 것을 권장한다.
